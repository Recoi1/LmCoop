# LmCoop 1.2.0

Player 2 now goes straight from joining to Player 1's current game. The joining
player sees the supplied loading artwork while connecting, waiting for the host
to finish the menus, and loading the host's map. There is no local file selection.

The host's current progress and spawn position are sent in a small game-state
packet. Player 2 starts in the host's room, follows host map changes, and keeps
their personal saves untouched. Lost connections show the loading screen again;
Back to start returns to the launcher to change connection details.

Both players must update together: the online protocol changed for direct joining.
Each PC still needs its own USA disc dump (GLME01 revision 0). Online co-op remains
experimental; this change does not add full authoritative simulation of every enemy
or event across PCs.
