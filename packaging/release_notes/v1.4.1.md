**LmCoop 1.4.1: Steam support is in the download.**

- **Play over Steam, with no matchmaking server.** Multiplayer > Settings > "Use Steam instead of a matchmaking
  server", then Host Online / Join by Code / Browse Lobbies as before. Lobbies, invite codes and the relay come
  from Steam. **Steam must be running and logged in.** The game uses Valve's public test app 480 ("Spacewar"),
  so Steam shows you as playing Spacewar. `steam_api64.dll` is included in the folder.
- **The lobby shows Steam names and profile pictures** (it shows the names you typed for Direct Connect and
  matchmaking-server lobbies).
- The lobby screen from 1.4.0 is included: only the host can start the game.
- **Not tested yet:** a real session between two different Steam accounts (the data path and the relay, and
  Browse Lobbies listing someone else's lobby). On one PC the lobby, the invite code, joining by code and the
  version check work. Also untested: two separate home networks over the other transports, a TURN relay, `wss://`.
- Not included: voice chat.

Includes everything in 1.4.0 and earlier. No retail game data is included; supply your own USA disc dump
(GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are used, and the
Steamworks SDK's `steam_api64.dll` is redistributed with the program; see NOTICE.md.
