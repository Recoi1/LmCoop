**LmCoop 1.3.0: internet co-op with invite codes (no Radmin or port forwarding in most cases).**

- **Host Online / Join by Code / Browse Lobbies** on the Multiplayer screen. The host gets a 6-character
  invite code (F1 > Controls > Online, with a Copy button); the friend types it in. Connections are
  peer to peer over encrypted WebRTC data channels, using STUN for NAT traversal.
- **A matchmaking server is required and none is hosted for you.** It is a small Node.js program in
  `server/`; see `docs/ONLINE_SERVER.md` to run your own, then enter its address under
  Multiplayer > Settings. No relay is provided: strict NATs may need a TURN server you run yourself.
- **Direct Connect** (LAN, Radmin, VPN) works as before.
- Privacy: a direct connection shows each player's public IP to the other player. See
  `docs/ONLINE_PLAYERS.md`.
- **Not yet tested:** two separate home networks, TURN, `wss://`. Tested so far: two game instances on
  one PC, and the server's own tests.

Includes everything in 1.2.3 and earlier. No retail game data is included; supply your own USA disc
dump (GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are added; see
NOTICE.md.
