**LmCoop 1.7.0: one-click crash reports.**

- **If LmCoop crashes**, the next start asks: "LmCoop crashed last time. Send a crash report to Recoi1?" Press
  **Send report**, add a note if you like, and it uploads and shows a report number. No GitHub account needed.
- **What is sent:** the crashed session's log and error stack, the game version and build, your Windows and graphics
  card, whether you were hosting or joining, your active mods, and your note. Passwords, IP addresses, Steam ids,
  invite codes, e-mail addresses, your user name and personal folders are removed first; saves and game files are
  never read. Details: `docs/CRASH_REPORTS.md`.
- **Each crash is kept separately** before the next start replaces its log, and a report that could not be uploaded
  stays saved and is sent the next time.
- **Not active yet:** the crash inbox (`server/crash-inbox`, a small Cloudflare Worker that files each report as an
  issue in a private GitHub repository) has to be deployed by the developer, and its address put in
  `data/crash_inbox.json`. Until then the prompt does not offer to send. The game never holds a GitHub credential.
- Windows only so far. Tested end to end with a local inbox: a crash is saved, uploaded, scrubbed (checked against a
  log full of fake secrets) and numbered, and a report sent while the inbox was down was kept and sent later.

Includes everything in 1.6.0 and earlier. No retail game data is included; supply your own USA disc dump
(GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are used, and the
Steamworks SDK's `steam_api64.dll` is redistributed with the program; see NOTICE.md.
