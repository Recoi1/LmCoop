**LmCoop 1.3.2: the program is now LmCoop.exe, with the LM logo as its icon.**

- **The program is called `LmCoop.exe`** (it was `LuigisMansionRecomp.exe`) and has the new LM icon.
- A copy under the old name, `LuigisMansionRecomp.exe`, is still in the package for this release, only so
  that older versions can update to it (their updater looks for that file). New installs can ignore it, and
  any shortcut you made to the old name keeps working.
- Linux and macOS packages keep the old program name for now.
- Everything in 1.3.1 (internet co-op with invite codes, shared cutscenes, synced flashlight aim and
  facing, joiners standing beside the host) is included. A matchmaking server is still something you run
  yourself (`docs/ONLINE_SERVER.md`). Not tested yet: two separate home networks, a TURN relay, `wss://`.

Includes everything in 1.3.1 and earlier. No retail game data is included; supply your own USA disc dump
(GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are used; see
NOTICE.md.
