**LmCoop 1.4.0: a lobby screen before the game starts.**

- **Host, then wait in a lobby.** After Create lobby (or Open lobby on Direct Connect) the host lands in a lobby
  that shows both players' names and the invite code (with a Copy button). **Only the host can start the
  game**, and when they do, both PCs boot into it. The joining player waits in the same lobby ("Waiting for
  the host to start the game...") instead of a loading screen, and can leave at any time.
- Works for Direct Connect (LAN, Radmin, VPN) and for internet lobbies alike.
- Steam avatars and Steam names in the lobby, and the Steam transport itself, exist only in builds made with
  the Steamworks SDK (`docs/ONLINE_STEAM.md`); this download does not include Steam support.
- **Not in this release:** voice chat (planned: a toggle, proximity-based in the game and plain in the lobby).
- Not tested yet: two separate home networks, a TURN relay, `wss://`, and anything over Steam between two
  accounts. The lobby was tested with two instances on one PC over Direct Connect and over a local matchmaking
  server.

Includes everything in 1.3.3 and earlier. No retail game data is included; supply your own USA disc dump
(GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are used; see
NOTICE.md.
