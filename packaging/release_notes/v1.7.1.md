**LmCoop 1.7.1: crash reports now work end to end, plus a live problem monitor.**

- **Crash reports are live.** After a crash, the next start offers **Send report**; it goes to the developer's private
  crash channel (no account needed). Scrubbing and what is sent are unchanged (`docs/CRASH_REPORTS.md`).
- **A crashed run's log is no longer lost.** If the old log could not be renamed (a process still closing, such as the
  old version right after an update restart), it is copied instead, so the crash trace survives for the report.
- **Updating no longer counts as a failed start**, which could show a false recovery prompt on the first launch after
  an automatic update.
- **New: `LmCoop-Monitor.cmd`.** Start the game with it to get a live window that shows only warnings, errors and
  crashes from the run log, and a clear "GAME CRASHED" message with the reason when it dies. It closes when the game
  closes. Optional: starting `LmCoop.exe` directly works as before.
- Windows only for the monitor. A portable install is found by its `last_run.log` beside the program.

Includes everything in 1.7.0 and earlier. No retail game data is included; supply your own USA disc dump
(GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are used, and the
Steamworks SDK's `steam_api64.dll` is redistributed with the program; see NOTICE.md.
