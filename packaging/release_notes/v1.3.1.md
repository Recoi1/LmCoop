**LmCoop 1.3.1: the 1.3.0 release build fixed, cutscenes and aim in sync, joiners no longer stand inside the host.**

- **Fixes the 1.3.0 build.** The 1.3.0 packages were never produced (the install step failed on all three
  platforms); this release has everything 1.3.0 announced: internet co-op with invite codes (Host Online,
  Join by Code, Browse Lobbies), over encrypted WebRTC, with a matchmaking server you run yourself
  (`docs/ONLINE_SERVER.md`; none is hosted for you). Direct Connect (LAN, Radmin, VPN) works as before.
- **Cutscenes are shared.** The host picks when a cutscene starts and both players watch it; dialogue
  choices wait for both. A player who joins while the host is in a cutscene now finishes joining (it used
  to stall on the loading screen).
- **The other player's flashlight, vacuum and facing are in sync.** Mouse aim and mouse turning are now
  sent to the other PC, so Mario's beam points where Mario aims.
- **A joining player stands beside the host's player**, not inside them.
- Not tested yet: two separate home networks, a TURN relay, `wss://`, dialogue choices in a shared
  cutscene, the opening and ending scenes. Players on strict NATs may need a TURN server you run.
- Direct connections show each player's public IP address to the other player (`docs/ONLINE_PLAYERS.md`).

Includes everything in 1.3.0, 1.2.3 and earlier. No retail game data is included; supply your own USA
disc dump (GLME01 revision 0).

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. libdatachannel (MPL-2.0), MbedTLS and nlohmann/json are added; see
NOTICE.md.
