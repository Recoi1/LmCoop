Initial Windows release of **LmCoop**, an independent project based on [rob646464/luigis-mansion-recompiled](https://github.com/rob646464/luigis-mansion-recompiled).

**Bring your own USA Luigi's Mansion disc dump (GLME01 revision 0). No retail game data, generated game modules or saves are included.**

## Download

Extract the entire ZIP and run `LuigisMansionRecomp.exe`. Drag your USA ISO/RVZ onto the setup screen, or use Browse. The bundled LLVM compiler builds the game module locally. Choose Singleplayer or Multiplayer after setup.

## LmCoop changes

- LmCoop setup screen and logo, USA-disc drag and drop.
- Singleplayer / Multiplayer start menu on every launch.
- Experimental online Host / Join mode: host plays Luigi, guest plays Mario.
- Mouse selection on the file selection screen.
- Mouse aiming and local crash-test work carried onto the 1.1.5 runtime.
- Updates now point to Recoi1/LmCoop.

For multiplayer, both PCs need this build and their own USA dump. Use a reachable host address and matching port/password. The current UI recommends a shared Radmin VPN network for internet play.

## Verification and limits

The Windows launcher builds successfully. The packaged executable reached the first-run disc screen with fresh test data. The bundled compiler/linker run, all 78 renderer patches reproduce the 69 modified renderer files, and the ZIP passed an integrity check. Source history was checked for game-data files and common credential patterns.

Online co-op remains experimental: two-PC synchronization and a full campaign have not been verified for this release. The underlying two-player mode is unfinished in some areas. Back up saves before trying multiplayer. This release contains a Windows package only.
