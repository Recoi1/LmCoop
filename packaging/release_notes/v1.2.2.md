**LmCoop 1.2.2 fixes aiming the flashlight up and down with the arrow keys or a gamepad.**

- **Up/down aim works again after you use the mouse.** In 1.1.12 to 1.2.1, once the mouse had moved
  up or down in a room, the arrow keys (and a gamepad's right stick) could no longer tilt the
  flashlight, because the mouse's pitch was held every frame. A stick press now takes over, and the
  mouse picks up from wherever the game leaves it.
- How it works, in case it was unclear: mouse up aims the flashlight (and the camera) up and mouse
  down aims it down, 1:1. The game only allows about 0 to 29 degrees, from straight ahead down to the
  floor. The arrow keys and the gamepad stick keep the game's own direction: up lowers the beam and
  down raises it.

Includes everything in 1.2.1 (W A S D relative to the mouse facing) and earlier. No retail game data
is included; supply your own USA disc dump (GLME01 revision 0).
