**LmCoop 1.1.8 adds Settings and update checking to the start screen.**

- The running version is shown in the bottom-right corner before gameplay.
- Automatic update checks now run on the start screen. Click the status to view release
  notes, retry a check, download an update, or install and restart.
- A Settings button opens the shared visuals, sound and controller/keyboard/mouse options,
  including before a disc is installed. Changes are saved for gameplay.
- Update controls and update notices have been removed from the in-game F1 menu.
- Includes the Mario skinning fix from 1.1.7.

Nothing is downloaded or installed without a click. Saves, settings and installed game
data remain separate from program updates. Supply your own USA Luigi's Mansion disc dump
(GLME01 revision 0); no retail game data is included.

Based on rob646464/luigis-mansion-recompiled, with Aurora by encounter and the
SomeJakeGuy/lm-decomp reference. Existing notices and component licenses are included.
